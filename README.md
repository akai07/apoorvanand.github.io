# Apoorv Anand - Interactive Portfolio

🚀 **Live Demo**: [https://akai07.github.io/apoorvanand.github.io](https://akai07.github.io/apoorvanand.github.io)

## Overview

A modern, responsive, and interactive portfolio website showcasing my skills, experience, and projects as a Technical Solutions Professional and Full Stack Developer. Built with cutting-edge web technologies and designed with a focus on user experience and performance.

## ✨ Features

- **Interactive Skills Visualization**: Radar chart showing skill balance across different domains
- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Performance Optimized**: Fast loading with optimized assets and lazy loading
- **SEO Friendly**: Proper meta tags and semantic HTML structure
- **Accessibility**: ARIA labels and keyboard navigation support
- **Interactive Timeline**: Expandable career journey with detailed achievements
- **Project Showcase**: Detailed project cards with live demos and source code links

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS
- **Charts**: Chart.js for interactive data visualization
- **Fonts**: Inter (Google Fonts)
- **Icons**: Heroicons (SVG)
- **Deployment**: GitHub Pages

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/apoorvanand/apoorvanand.github.io.git
   cd apoorvanand.github.io
   ```

2. **Open in browser**
   ```bash
   # Simply open the HTML file in your browser
   open ApoorvAnand.html
   # or
   start ApoorvAnand.html
   ```

3. **For development with live server**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (if you have live-server installed)
   npx live-server
   ```

The portfolio is fully responsive and optimized for:
- 📱 Mobile devices (320px and up)

## 🎨 Design Philosophy

- **Modern & Professional**: Clean design that reflects technical expertise

- Lazy loading for images and scripts
- Optimized CSS with minimal unused styles

## 🔧 Customization

To customize this portfolio for your own use:

1. **Update personal information** in the HTML file
2. **Modify the skills data** in the Chart.js configuration
3. **Replace project information** with your own projects
4. **Update social media links** in the sidebar
5. **Customize colors** by modifying the Tailwind CSS classes
